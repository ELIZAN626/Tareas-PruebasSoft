# System tests BDD

Pruebas de sistema con `behave` + `selenium` usando tabla de datos (DDT).

## Archivos

- `features/uni_search.feature`
- `features/steps/university_steps.py`
- `features/environment.py`

## Instalar

```bash
pip install -r system_tests/requirements.txt
```

## Ejecutar

```bash
behave system_tests/features
```
